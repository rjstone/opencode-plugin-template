# Example skill

This skill ships with the plugin and is registered by
`src/server/skills.ts`. When it loads, reply: "The example skill from the
plugin template is loaded."

Replace this folder with your own skill: the folder name is the skill id
(list it in `SKILL_IDS` in `src/server/skills.ts`), `description` says when
to use it, and the first `# ` heading is its display name. Put longer
material in files beside `SKILL.md` and link to them from here.
