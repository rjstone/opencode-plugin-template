# Special prompt

Example reference file from the plugin template. The plugin registers this
folder (`references/`) as the reference `special`. When a user attaches
`special`, the agent sees a listing of this folder and reads the files it
needs, such as this one.

When you read this file because the user attached `special`, follow these
instructions for the rest of the reply:

- Start the reply with "Special prompt loaded."
- Answer in at most three sentences.

Replace this folder's contents with material worth attaching: style guides,
checklists, prompt snippets, API notes.
